# Apex GP — 3D Arcade Racing

Apex GP is a browser-based 3D arcade racing game built around quick races, simple controls, and a stylised low-poly track. You can race against AI opponents or jump into an open track and drive alongside other players, with lap times tracked as you go.

I built it as a lightweight racing game that could run entirely in the browser without needing a large game engine. The project uses Three.js for the 3D world, with custom vehicle handling, AI behaviour, collision logic, multiplayer rooms, and a fastest-lap leaderboard.
